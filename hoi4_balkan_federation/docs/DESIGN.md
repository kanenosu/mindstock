# バルカン連邦 MOD 設計メモ

## 目的
HoI4 1.19 系で、1936年時点にユーゴ・ブルガリア・アルバニアを統合した架空国家「バルカン連邦」(BLK) を追加する。他国はバニラのまま、連邦に関係する部分だけイベント・決定・専用方針で変更する。全テキストは日本語。

## 方針
1. **バニラ／DLC ファイルの上書きを避ける**。他国の方針ツリーは触らず、イベントで選択式の専用ツリー (`load_focus_tree`) を提供する。
2. **ステート定義は同梱しない**。ゲーム本体から生成するスクリプト (`tools/generate_from_game.*`) を用意し、未実行時は `on_startup` のフォールバックで併合処理する。
3. **ステートIDへの依存を最小化**。所有権の移転はタグベース（`is_core_of` / `annex_country`）で行い、個別IDは建設・請求権など「失敗しても致命的でない」効果に限定し、`owns_state` ガードを付ける。
4. **指導者の切替は `add_country_leader_role` で行う**。同じ政党に複数の指導者候補（ティトー／ディミトロフ、ヴェルチェフ／ネディッチ）を用意し、イベントで選ぶ。

## 連邦の開始状態
- 首都 107（ベオグラード）、研究枠 3、安定 45%、戦争支持 35%
- 政体：中道（連邦摂政評議会）、支持率 中道45 / 民主25 / ファシ15 / 共産15
- 国民精神 5 つ（未完の連邦・多言語の軍隊・三王評議会・IMROの影・イタリアの経済的圧力）
- 軍：生成された `BLK_1936.txt`（21個師団）。未生成時は旧三国の軍を `transfer_troops` で引き継ぐ

## 国家方針ツリーの配置
| 枝 | x 範囲 | 方針数 |
|---|---|---|
| 外交 | 0–7 | 12 |
| アドリア海 | 8–10 | 5 |
| 政治（4路線） | 11–25 | 41 |
| 連邦統合 | 29–31 | 6 |
| 産業 | 35–39 | 13 |
| 軍事 | 45–54 | 17 |

政治枝の4路線は `mutually_exclusive`。AI は `on_startup` で抽選したフラグ (`blk_ai_path_*`) に従い、`ai_strategy_plans` で路線を固定する。

## イベント名前空間
- `blk.*` 連邦国内（1–9 フレーバー、20–26 路線関連、30–32 統合、90–92 返答）
- `blkf.*` 他国（1–9 開始時反応、10–19 連邦の提案への応答、21–25 要求への応答）
- `blknews.*` ニュース（2–9）

## 他国との相互作用の流れ
```
BLK 方針/決定 ──country_event──▶ 他国の応答イベント（ai_chance）
                                      │
                                      ├─ 受諾 → 効果適用 + BLK に blk.90
                                      └─ 拒否 → BLK に blk.91（最後通牒の場合は戦争目標）
```

## 既知の未検証事項
- ポートレート／方針アイコン／イベント画像はバニラの汎用アセット名を参照している。アセット名が存在しない場合は空白表示になるが、クラッシュはしない。
- ゲーム内での実機テストは本環境では行えていない。`error.log` を確認しながら調整すること。
