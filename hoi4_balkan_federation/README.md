# バルカン連邦 (Balkan Federation 1936) — Hearts of Iron IV MOD

**対応バージョン: 1.19.x（Thunder at our Gates 以降）**

1936年1月1日時点で、ユーゴスラヴィア・ブルガリア・アルバニアが統合した架空国家「バルカン連邦」(国タグ `BLK`) が成立している世界のMODです。他の国は基本的にバニラのままですが、連邦の成立に周辺国が反応するイベント・決定・専用国家方針を追加しています。テキストはすべて日本語です（英語環境でも日本語で表示されます）。

---

## 1. 世界観

| 年月 | 出来事 |
|---|---|
| 1934年5月 | ソフィアでズヴェノ将校団のクーデタ。キモン・ゲオルギエフ政権はユーゴスラヴィアとの和解路線へ |
| 1934年10月 | マルセイユで国王アレクサンダル1世が暗殺される。摂政パヴレが即位 |
| 1935年3月 | 「ベオグラード＝ソフィア連合条約」調印。両国の連邦化が決定 |
| 1935年9月 | イタリアの経済的締め付けに苦しむアルバニアのゾグ1世が加盟を決断 |
| 1936年1月 | **バルカン連邦**成立。首都ベオグラード。元首は摂政パヴレ・ボリス3世・ゾグ1世による「三王評議会」 |

連邦は統一された行政も軍も通貨も持たない「未完の連邦」として始まります。セルビア中央集権派、クロアチア農民党（マチェク）、ブルガリア将校団（ズヴェノ）、地下の共産主義者（ティトー／ディミトロフ）が、連邦の進路を争います。

## 2. 連邦のコンテンツ

### 国家方針ツリー（94方針）
- **政治枝**：制憲議会から4つの排他的な路線へ
  - **王冠の連邦**（中道）：三王評議会の制度化 → バルカン協商の盟主 → 武装中立／ペータル2世の即位 → 「バルカンの守護者」
  - **民衆の連邦**（民主主義）：クロアチア協定 → 連邦総選挙（マチェク政権） → 西側借款 → 連合国加盟 or 民主バルカン同盟
  - **将校団の連邦**（軍事評議会／ファシズム枠）：ズヴェノの台頭 → 軍事評議会（ヴェルチェフ or ネディッチ） → 枢軸接近 or 第三の道 → 大バルカン連邦（テッサロニキ進軍・ドブロジャ最後通牒）
  - **赤い連邦**（共産主義）：ディミトロフの帰国 → 社会主義連邦（ティトー or ディミトロフ） → コミンテルン路線 or バルカン独自の道 → 革命の輸出・半島の解放
- **連邦統合枝**：IMRO掃討 or マケドニア自治 → アルバニア協定 → 連邦市民権法 → 多民族一連邦
- **外交枝**：ギリシャ・ルーマニア・トルコへの接近、テッサロニキ自由港、ドブロジャ協定、連邦加盟交渉（相手国を連邦構成国＝従属国に）、全バルカンの統合
- **アドリア海枝**：イタリアとのデタント（不可侵条約） or アドリア海防衛（ザラ・イストリアへの要求）
- **産業枝**：ソフィア＝ベオグラード幹線、ボル・トレプチャ鉱山、ゼニツァ製鉄所、アルバニア油田、連邦銀行、研究枠追加
- **軍事枝**：統合参謀本部、山岳軍団、連邦空軍、アドリア艦隊、国境要塞線、「バルカンの盾」

### 国民精神（開始時）
未完の連邦 / 多言語の軍隊 / 三王評議会 / IMROの影 / イタリアの経済的圧力

### 人物
- 指導者候補：パヴレ摂政、ペータル2世（1941年以降）、マチェク、ヴェルチェフ、ネディッチ、ティトー、ディミトロフ
- 顧問：ゲオルギエフ、ストヤディノヴィチ、コロシェツ、ツァンコフ、ゾグ1世、シュバシッチ
- 将軍：シモヴィチ、ストイチェフ、ルカシュ、コシッチ、ペルヴィジ / 提督：ポリッチ

### 決定
- **連邦統合**：クロアチア／スロヴェニア／ブルガリア／マケドニア／アルバニア統合計画（5つ完了で「未完の連邦」軽減）、IMRO掃討作戦、連邦軍指揮言語学校
- **大バルカン**：構成国（ギリシャ／ルーマニア）の完全統合、大バルカン連邦の宣言（コスメティックタグ・専用国旗）

### イベント
連邦の黎明、制憲議会、クロアチア農民党の要求、ゾグ王の不満、ボリス3世と将校団、マルセイユの記憶、IMROの爆弾（反復）、ストヤディノヴィチの経済構想、クロアチア独立の危機、指導者選択イベント、ペータル2世の即位 など

## 3. 他国側の変更

| 国 | 追加内容 |
|---|---|
| ギリシャ | 開始イベント「北の巨人」（協調／警戒／**専用国家方針ツリーへの切替**）、連邦からの接近・加盟提案・陣営招請への応答イベント、決定「連邦との国境協定」「対連邦防衛線」 |
| ルーマニア | 開始イベント「南の連邦」（同上、**専用ツリー**あり）、ドブロジャ協定／最後通牒への応答、決定 |

| ハンガリー | 開始イベント「南方の脅威」、決定「ヴォイヴォディナの要求」 |
| ドイツ | 開始イベント「バルカンの資源」、決定「バルカン通商使節団」、枢軸加盟申請への応答 |
| ソ連 | 開始イベント「バルカンの同志たち」、決定「バルカン共産党への支援」、コミンテルン加盟への応答 |
| イギリス／フランス | 開始イベント（関係強化／距離）、連合国加盟申請への応答 |
| トルコ | 開始イベント「西の連邦」、海峡協約、陣営招請への応答 |

ギリシャとルーマニアの専用ツリー（各14方針）は、開始イベントで選んだ場合のみ読み込まれます。バニラ／DLCの方針ツリーはファイル上書きしていないので、他のMODとの競合は最小限です。

バニラでユーゴ・ブルガリア・アルバニアを対象にしていた方針（ドイツの「ユーゴスラヴィアの運命」、イタリアのアルバニア併合、ハンガリーの対ユーゴ要求、ブルガリア関連など）は、対象国が存在しないため自動的に実行不能になります。

## 4. インストール

### 4-1. MODフォルダの配置
1. このフォルダの中身を `Documents/Paradox Interactive/Hearts of Iron IV/mod/balkan_federation/` にコピー
2. 同梱の `balkan_federation.mod` を `Documents/Paradox Interactive/Hearts of Iron IV/mod/` に置く
3. ランチャーのプレイセットで「バルカン連邦」を有効化

### 4-2. ステート上書きの生成（**必須・初回のみ**）
HoI4 のステート定義ファイル（プロヴィンス一覧を含む）は Paradox の著作物のため、このMODには同梱していません。代わりに、お手元のゲーム本体から自動生成するスクリプトを用意しています。

**Python がある場合**
```
python tools/generate_from_game.py "C:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV"
```

**Python がない Windows の場合（PowerShell）**
```
Set-ExecutionPolicy -Scope Process Bypass
.\tools\generate_from_game.ps1 "C:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV"
```

スクリプトは以下を生成します。
- `history/states/` … 旧三国の全ステートの所有者を `BLK` に書き換えた上書きファイル（中核化も追加。旧国の中核は残るので、後から解放も可能）
- `history/countries/YUG|BUL|ALB - *.txt` … 旧三国の軍編成読み込みを無効化
- `history/units/BLK_1936.txt` … 連邦軍の初期編成（21個師団 + 旧三国の航空隊）
- `history/units/BLK_1936_naval_*.txt` … 旧三国の海軍を統合した連邦海軍

ゲームのアップデート後に挙動がおかしくなった場合は、スクリプトを再実行してください。

> **スクリプトを実行しなかった場合**：ゲーム開始直後に `on_startup` で旧三国を連邦に併合するフォールバックが動きます。ゲーム自体は進行しますが、ロビー画面で連邦を選択できない（開始時点で領土を持たないため）という制約があります。他国でプレイする分には問題ありません。

## 5. 既知の制約・注意
- **ポートレート**はすべてバニラの汎用ポートレートを使用しています。差し替える場合は `common/characters/BLK.txt` の `portraits` のパスを変更してください。
- **国旗**は `tools/make_flags.py` で生成した簡易デザインです（汎スラヴ三色＋金星）。任意の 82x52 / 41x26 / 10x7 の TGA に差し替え可能です。
- **1939年シナリオ**は正式には対応していません（起動はします）。
- ステートIDはバニラ 1.19 時点のものを `common/scripted_triggers/BLK_scripted_triggers.txt` と `tools/generate_from_game.py` の `CITY_STATES` に集約しています。ゲームのアップデートで ID が変わった場合はここを修正してください。
- 他国の方針ツリーは上書きしていないため、ブルガリア／ユーゴスラヴィア用の DLC コンテンツ（Battle for the Bosporus / Death or Dishonor の該当部分）はこのMODでは使われません。
