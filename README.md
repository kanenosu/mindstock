# MindStock — 人生チャート日記アプリ

**ただ日記を書くだけで、人生が株価のローソク足チャートとして可視化されるアプリ。**

書いた文章をAIが解析して出来事の重要度を判定し、人生の軌跡を一本のチャートとして描き続けます。詳細な設計は [docs/SPEC.md](docs/SPEC.md) を参照。

## コア体験

```
日記を書く → AIが即座に採点 → その日のローソク足が自動反映（確認なし）
```

- **入力の3階層**: しっかり書く / 気分スライダーだけ / 何もしない（空白＝平穏な日。罰しない）
- **AI委任型・足し算モデル**: `今日の値 = 前日の値 + 出来事の点数合計`。快楽順応・損失回避はAIの採点プロンプトに織り込む
- **ローソク足表示**: 高値=ポジティブの積み上げ、安値=ネガティブの積み上げ。「マイナスを飛び越えてトータルでプラス」の日は下ヒゲの長い陽線になる
- **成長の実感**: 過去の自分との多重比較（昨日/1ヶ月前/半年前/1年前）、ピンチズームで谷の時期を拡大、当時の生の言葉の振り返り

## 画面構成

| 画面 | 役割 |
|---|---|
| ホーム（ダッシュボード） | Life Index・日/週/月切替のミニチャート（横ドラッグでスクロール）・クイック入力・最近の記録 |
| 日記 | カレンダー（緑●=プラス/赤●=マイナスの日、タップで即移動）・本文入力・マイク長押しで音声入力・気分絵文字 |
| 推移 | 日足は点＋ライン、週足・月足はローソク足。移動平均、ピンチズーム・スクロール、タップで振り返りへ |
| 記録 | 記録した日のリスト。各日 → 振り返り → 出来事の微調整（編集画面） |
| 設定 | AI解析・音声入力のAPIキー、サンプルデータ投入・全削除 |

全画面でボトムナビの横スワイプによるタブ切替に対応（内側のチャートのピンチズーム・ドラッグ操作とは競合しない）。

## AI解析・音声入力

- **AI解析**: APIキー未設定時は端末内の簡易解析（文単位抽出＋快楽順応・損失回避の擬似採点）。Claude APIキーを設定すると文脈を読んだ本解析に切り替わる
- **音声入力**: 日記入力画面のマイクを長押しして話すと、OpenAI Whisper APIで文字起こしされ本文に追記される。OpenAI APIキーの設定が必要

## 技術スタック

- **Flutter** (Android優先、後にiOS)
- 状態管理: **Riverpod**
- ローカルDB: **sqflite**
- AI解析: **Claude API** (`claude-opus-4-8`) — 構造化出力で「日記文章 → 出来事リスト」を抽出。APIキー未設定時はキーワードベースの簡易解析にフォールバック
- 音声入力: **OpenAI Whisper API** (`whisper-1`) — `record`パッケージで録音し、文字起こし結果を本文に追記

## 開発

```bash
flutter pub get
flutter test      # チャートロジック・解析のユニットテスト
flutter analyze
flutter run       # Android端末/エミュレータ
```

主要ソース:

- `lib/logic/chart_calculator.dart` — 足し算モデル・OHLC算出・週足/月足集約・移動平均
- `lib/services/diary_analyzer.dart` — Claude API解析（快楽順応・損失回避のプロンプト）+ フォールバック
- `lib/services/transcription_service.dart` — Whisper音声文字起こし
- `lib/widgets/candlestick_chart.dart` — CustomPainterによるローソク足描画
- `lib/widgets/voice_input_button.dart` — 長押し録音→文字起こしのマイクボタン
- `lib/widgets/diary_calendar.dart` — 記録ドット付きカレンダー
- `lib/providers.dart` — 状態管理と「書く→解析→反映」フロー
