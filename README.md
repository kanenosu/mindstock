# MindStock — 人生チャート日記アプリ

**ただ日記を書くだけで、人生が株価のローソク足チャートとして可視化されるアプリ。**

書いた文章をAIが解析して出来事の重要度を判定し、人生の軌跡を一本のチャートとして描き続けます。詳細な設計は [docs/SPEC.md](docs/SPEC.md) を参照。

## コア体験

```
日記を書く → AIが即座に採点 → その日のローソク足が自動反映（確認なし）
```

- **入力の3階層**: しっかり書く / 気分スライダーだけ / 何もしない（空白＝平穏な日。罰しない）
- **AI委任型・足し算モデル**: `今日の値 = 前日の値 + 出来事の点数合計`。快楽順応・損失回避はAIの採点プロンプトに織り込む
- **ローソク足表示**: 高値=ポジティブの積み上げ、安値=ネガティブの積み上げ。「マイナスを飛び越えてトータルでプラス」の日は下ヒゲの長い陽線になる
- **成長の実感**: 過去の自分との多重比較（昨日/1ヶ月前/半年前/1年前）、ピンチズームで谷の時期を拡大、当時の生の言葉の振り返り

## 画面構成

| 画面 | 役割 |
|---|---|
| チャート | ローソク足（日足/週足、移動平均、ピンチズーム・スクロール、タップで振り返りへ） |
| 書く | 日記入力 + 気分スライダー。送信で即AI解析・即反映 |
| 一覧 | 記録した日のリスト。各日 → 振り返り → 出来事の微調整（編集画面） |
| 設定 | Claude APIキー（未設定でも簡易解析で動作） |

## 技術スタック

- **Flutter** (Android優先、後にiOS)
- 状態管理: **Riverpod**
- ローカルDB: **sqflite**
- AI解析: **Claude API** (`claude-opus-4-8`) — 構造化出力で「日記文章 → 出来事リスト」を抽出。APIキー未設定時はキーワードベースの簡易解析にフォールバック

## 開発

```bash
flutter pub get
flutter test      # チャートロジック・解析のユニットテスト
flutter analyze
flutter run       # Android端末/エミュレータ
```

主要ソース:

- `lib/logic/chart_calculator.dart` — 足し算モデル・OHLC算出・週足集約・移動平均
- `lib/services/diary_analyzer.dart` — Claude API解析（快楽順応・損失回避のプロンプト）+ フォールバック
- `lib/widgets/candlestick_chart.dart` — CustomPainterによるローソク足描画
- `lib/providers.dart` — 状態管理と「書く→解析→反映」フロー
